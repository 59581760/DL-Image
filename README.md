# DL-Image

### English
This is a Deep Learning exercise code based on related medical imaging data. It is divided into 6 parts: 01 classification (2D), 02 segmentation (3D), 03 registration, 04 detection, 06 endoscopy, and 07 multimodal classification.

**Data Sources:**
- `01`: MedNIST
- `07`: RXRX1

---

**数据来源：**
